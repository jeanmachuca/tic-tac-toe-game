# Tic-Tac-Toe Game

Vanilla JS game — no build step, no dependencies, no package manager.

## Commands

```bash
# Serve locally (any static file server)
python3 -m http.server 8080
# or: npx serve .
```

## Dev notes

- All state (board, player, scores) is in `script.js` — no framework
- Win patterns are hardcoded in `winPatterns`
- To run: open `index.html` in any browser or serve via any static server
