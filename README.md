# Tic-Tac-Toe

A classic Tic-Tac-Toe game built with vanilla HTML, CSS, and JavaScript.

## Play

Open `index.html` in a browser. Player X starts — click any cell to place your mark.

## Features

- Two-player local game (X and O)
- Win detection with highlighted winning line
- Draw detection
- Persistent scoreboard (X wins, O wins, draws)
- Reset button for new rounds
- Dark neon theme
